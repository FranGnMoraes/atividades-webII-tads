# Exemplo CSR — Aula 01

```bash
npm install
npm test    # testes automatizados (Vitest + Supertest)
npm run dev  # compila o bundle do cliente e sobe o servidor em http://localhost:3001
```

Veja `src/server.ts` (o servidor só devolve o casco HTML e o JSON) e `src/main.ts` (o código que roda no navegador e monta a tela). Compare com o projeto irmão em `../ssr`.
