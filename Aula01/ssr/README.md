# Exemplo SSR — Aula 01

```bash
npm install
npm test    # testes automatizados (Vitest + Supertest)
npm run dev  # http://localhost:3000
```

Veja `src/server.ts` — a rota `GET /` monta o HTML completo (com as tarefas) no servidor e envia pronto para o navegador. Compare com o projeto irmão em `../csr`.
